# منصة الريان في الدراسات التاريخية

منصة تعليمية عربية مبنية باستخدام Flask لمساعدة طالبات الصف الحادي عشر على دراسة التاريخ، حل أوراق العمل التفاعلية، مراجعة النتائج، والاستفادة من معلّم ذكي يعتمد على مصادر المنهج.

## المزايا الرئيسية

- لوحة منفصلة للمعلمة والطالب.
- رفع أوراق العمل ونشرها أو حفظها كمسودات.
- أسئلة اختيار من متعدد، صح أو خطأ، إجابة قصيرة، وأسئلة مقالية.
- تصحيح تلقائي للأسئلة الموضوعية وتصحيح يدوي للأسئلة المقالية.
- مؤقت للحل، حفظ تلقائي للإجابات، وتسليم تلقائي عند انتهاء الوقت.
- تحديد عدد المحاولات لكل ورقة.
- اختيار سياسة العلامة المعتمدة: الأعلى، الأخيرة، الأولى، أو المتوسط.
- لوحة نتائج وإحصائيات للمعلمة.
- صفحة نتائج ومحاولات للطالب.
- صفحة حساب لتعديل الاسم والبريد وكلمة المرور.
- صفحة «من نحن» قابلة للتعديل من لوحة المعلمة.
- بحث دلالي ومعلّم ذكي مبني على محتوى المنهج.

## التشغيل محليًا على Windows PowerShell

```powershell
cd "C:\Users\Apple\Desktop\alrayyan-history-platform"

Set-ExecutionPolicy `
-Scope Process `
-ExecutionPolicy RemoteSigned `
-Force

& ".\.venv\Scripts\Activate.ps1"

pip install -r requirements.txt
flask db upgrade
python -m scripts.verify_knowledge
python app.py
```

ثم افتحي:

```text
http://127.0.0.1:5000
```

## متغيرات البيئة

انسخي `.env.example` إلى ملف باسم `.env`، ثم ضعي القيم الحقيقية محليًا. لا ترفعي ملف `.env` إلى GitHub.

```env
SECRET_KEY=replace_with_a_secure_random_value
DATABASE_URL=sqlite:///alrayyan.db
OPENROUTER_API_KEY=your_private_key
```

## قاعدة البيانات

يجب تشغيل الأمر التالي بعد تنزيل أي نسخة تحتوي Migration جديدة:

```powershell
flask db upgrade
```

النسخة الحالية تصل إلى Migration:

```text
e6f719a82b31
```

## ملاحظة حول التصحيح الإلكتروني

الأسئلة التي تنشئها المعلمة داخل النشاط التفاعلي تُصحح إلكترونيًا، باستثناء الأسئلة المقالية. أما ملف PDF أو Word المرفوع للتنزيل فلا يتحول تلقائيًا إلى اختبار؛ تحويل الملفات المرفوعة إلى أسئلة قابلة للتصحيح هو تطوير مستقل للنسخة التالية.

## الحماية عند الرفع إلى GitHub

تتجاهل إعدادات Git الملفات التالية:

- `.env`
- `.venv`
- قاعدة بيانات SQLite داخل `instance`
- الملفات المرفوعة من المستخدمين
- ملفات المنهج الأصلية

قبل أي رفع، يمكن فحص المفاتيح بواسطة:

```powershell
git grep -n -I -E "sk-or-v1-|sk-proj-"
```
